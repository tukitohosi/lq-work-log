# 旧数据迁移到 L.Q记工本 2.1.1

Windows 安装包不会包含项目目录里的 `data` 文件夹，也不会自动读取浏览器旧版的数据。迁移时应先从旧版导出一份完整 JSON 备份，再在 2.1.1 安装版中恢复。这样既不会把真实记工数据带进安装包，也能让安装版先校验备份内容。

已安装 1.0.0、2.0.0 或 2.1.0 的用户可以直接运行 2.1.1 安装包升级；应用标识、EXE 名称和 `%APPDATA%\L.Q记工本\data` 数据目录保持不变。无论采用覆盖升级还是 JSON 恢复，都建议先另存一份完整备份。

## 从浏览器旧版导出

1. 启动旧版项目，确认原有工人和记工记录可以正常查看。
2. 点击界面中的“导出完整备份”，把 `.json` 文件保存到项目目录之外，例如桌面、U 盘或专用备份文件夹。
3. 确认 JSON 文件不是 0 字节，并保留旧版整个 `data` 文件夹，直到安装版迁移验收完成。
4. 不要把旧 `data` 文件夹复制到 `out`、`release` 或安装包目录中。

## 安装并恢复

1. 运行 `L.Q记工本-2.1.1-Setup.exe`。如安装包未使用代码签名证书，Windows 可能显示“未知发布者”提示。
2. 启动“L.Q记工本”。新安装首次打开时显示空数据属于正常现象；覆盖升级则应继续显示原安装版数据。
3. 需要迁移浏览器旧版或另一台电脑的数据时，点击“恢复备份”，选择刚才导出的 JSON 文件并确认恢复。
4. 恢复后逐项核对：工人姓名与头像、最近一个月的上午/下午/加班、实际工地、日薪、单日和月备注、补贴扣款及工资合计。
5. 核对无误后，再从 2.1.1 导出一份新的完整备份。旧版数据至少保留到这一步完成。

恢复操作会先校验 JSON，并在覆盖现有数据前创建恢复前备份。不要手动编辑 JSON，也不要在应用运行时直接替换数据文件。

## schema v7 迁移

2.1.1 的数据版本为 schema v7。v1 至 v6 备份会先走既有迁移链，再补齐或保留以下字段：

- 工人 `avatarEmoji` 默认为 `null`；
- 月度记录 `paidAt` 默认为 `null`；
- 设置 `weeklyAutoBackupEnabled` 默认为 `true`；
- 设置 `lastWeeklyBackupAt` 默认为 `null`。
- 设置 `defaultOvertimePayPercent` 默认为 `100`，即 1 倍；
- 每条月记录 `overtimePayPercent` 默认为 `100`，历史工资保持不变。

迁移不会删除既有未来日期考勤，也不会自动把任何月份标记为已结清。图片头像继续保留；之后如果改用 Emoji 头像，图片与 Emoji 会按新规则互斥。未知的未来 schema 版本会被拒绝，避免新数据被旧程序误写。

## 安装版的数据与备份位置

安装版把正式数据保存在：

```text
%APPDATA%\L.Q记工本\data
```

通常对应：

```text
C:\Users\<你的用户名>\AppData\Roaming\L.Q记工本\data
```

其中包含：

- `records.json`：正式数据；
- `records.last-good.json`：最近有效副本；
- `backups`：程序内部的每日备份和恢复前备份。

2.1.1 Windows 桌面版还会在默认开启时，把每周外部 JSON 备份写入：

```text
Windows 文档\L.Q记工本备份
```

应用启动及运行期间会检查是否已满 7 天，只保留最近 12 份本程序固定前缀的周备份。设置页可查看上次成功时间、立即备份或打开目录。写入失败不会更新成功时间；应用关闭后不在后台驻留。浏览器启动方式不能使用此固定目录，仍需通过“导出完整备份”手动保存。

安装包、应用程序文件和用户数据互相分离。安装或升级不会把项目目录中的真实数据打入安装包，也不会用示例数据覆盖 `%APPDATA%` 中的记录。重装、卸载或更换电脑前，仍应先从界面导出完整 JSON 备份。

## 迁移后检查清单

- 至少抽查一名有图片头像的工人和一名归档工人；
- 对照旧版核对一个含考勤、加班、工地与补贴扣款的完整月份；
- 确认既有未来日期记录仍存在，但未来格只降低透明度，不出现“未来”文字或标签；
- 首次尝试修改未来日期时应出现会话级确认，取消后整次操作不应部分写入；
- 手动标记一个月份“已结清”，确认取消后不会锁住考勤或工资修改；
- Windows 桌面版执行一次“立即备份”，再从设置页打开备份目录并确认 JSON 可读取；
- 在设置页预览一份内部备份，确认列表不显示路径且恢复前会再建备份；
- 导出一份新 JSON，并在隔离测试数据上试恢复，确认 schema v7 可以完整往返。

## 校验安装包

发布目录中的 `.sha256` 文件记录安装包的 SHA-256。可在 PowerShell 中核对：

```powershell
$exe = '.\L.Q记工本-2.1.1-Setup.exe'
$actual = (Get-FileHash -Algorithm SHA256 -LiteralPath $exe).Hash.ToLowerInvariant()
$recorded = ((Get-Content -LiteralPath "$exe.sha256") -split '\s+')[0].ToLowerInvariant()
$actual -eq $recorded
```

结果应为 `True`；如不一致，不要继续安装，应重新获取安装包。
